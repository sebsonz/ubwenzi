# Frontend UBWENZI

Le frontend regroupe l'application Web et l'application mobile. Les interfaces consomment les contrats et l'API UBWENZI. Aucune logique d'autorisation frontend ne remplace le contrôle serveur.

Voir [la structure officielle du monorepo](../docs/architecture/UBWENZI-MONOREPO-STRUCTURE-V1.md).
