# Backend UBWENZI

Le backend est organisé en deux applications indépendantes : `api/` (NestJS + Fastify) et `worker/` (traitements asynchrones). Les primitives exclusivement backend résident dans `shared/`.

Les domaines D00 à D16 sont définis dans la documentation d'architecture. Aucun domaine ne doit être implémenté avant validation de ses spécifications, contrats, permissions, événements et tests.

Voir [la structure officielle du monorepo](../docs/architecture/UBWENZI-MONOREPO-STRUCTURE-V1.md).
